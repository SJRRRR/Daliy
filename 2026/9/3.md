# 形近词分组

## -ough / -ought 系列
though // 虽然，尽管
thought // 思想，想法，思考
thorough // 彻底的

## cas- 系列
casual // 随便的，偶然的，临时的
casualty // 受害者，伤亡人员

## medit- 系列
mediate // 调解，斡旋
meditation // 冥想，沉思

## 动词 -ate/-fy 系列
inaugurated // 就职，开创，举行开幕（落成）典礼
ventilate // 使通风，换气
certify // 证明，证实，颁发证书

## emb- 系列
embed // 嵌入
embody // 使具体化
embryo // 胚胎

## de- 系列
deem // 认为
degree // 程度，度数，学位
decree // 政令，法令，裁定
deduct // 扣除，减去

## bar- 系列
bar // 酒吧；条，杆；障碍；禁止
bargain // 讨价还价，交易，便宜货

## ab- 系列
abolish // 废除，取消
abroad // 在国外，到国外

## ce-/access 系列
access // 接近，进入，访问权
cease // 停止

# 其他单词

benevolent // 有善的
cautious // 谨慎的，小心的
elsewhere // 在别处，去别处
elementary // 初级的，基础的，小学的
fight // 战斗，打架
withdraw // 撤回，撤退，取款
captive // 被俘虏的，被监禁的；俘虏
behave // 有礼貌
challenge // 挑战，质疑
major // 主要的
upset // 不快
wit // 有智慧的
